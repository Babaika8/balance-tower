# Diner Skin Assets

Optional art overrides for the Diner location.

Supported files:

- `background.png` — full diner stage, if replacing code-drawn layers later.
- `pancake.png`, `pancake1.png`, `pancake2.png`, `pancake3.png`, `pancake4.png`
  — falling pancake sprites.
- `carrier.png` or `hand.png` — spatula/serving hand carrier.
- `pedestal.png` — plate under the pancake stack.

Pancake sprites must be transparent PNGs and should match the wide 180 x 56
physics silhouette. Keep toppings readable but do not make tall parts that imply
different collision.
