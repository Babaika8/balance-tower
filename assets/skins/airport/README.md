# Airport Skin Assets

Optional art overrides for the Airport location.

Supported files:

- `background.png` — full terminal stage, if replacing code-drawn layers later.
- `suitcase.png`, `suitcase1.png`, `suitcase2.png`, `suitcase3.png`,
  `suitcase4.png` — falling suitcase sprites.
- `carrier.png` or `hand.png` — baggage clamp / conveyor drop arm.
- `pedestal.png` — luggage cart under the stack.

Suitcase sprites must be transparent PNGs and should match the wide 180 x 56
physics silhouette. Handles can extend slightly upward, but the mass should read
as a horizontal suitcase.
